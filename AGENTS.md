# opal-downloader

**The rules for working in this repository live in [CLAUDE.md](CLAUDE.md).**
Read that file. It applies to every agent working here, whatever tool it runs
under — the filename says Claude, the contents do not.

Nothing else belongs in this file. It was a near-copy of `CLAUDE.md` until
2026-10-21, and by then the two had already drifted apart in both directions:
each carried a rule the other was missing, so which rules applied depended on
which tool you happened to start. One copy is the point. If a rule needs
changing, change it in `CLAUDE.md` — which needs the maintainer's permission,
as that file says.

For what the codebase *is*, rather than how to work on it, see
[docs/architecture.md](docs/architecture.md).
